❓ COMMON QUESTIONS:

Q: How do I add background music?
A: Get an MP3 file, name it "background.mp3", put in public/music/ folder

Q: Can I change fonts?
A: Yes, edit public/styles.css (advanced)

Q: How do I deploy online?
A: Follow DEPLOYMENT_GUIDE.md (15 minutes)

Q: Can multiple people edit settings?
A: Currently only one admin panel (you can add password protection)

Q: What if I need to restart?
A: Press Ctrl+C to stop, then "npm start" to restart

Q: Where is my data stored?
A: In data/ folder as JSON files

Q: Can I add more colors?
A: Yes, edit styles.css (advanced)

📞 TROUBLESHOOTING:

Problem: npm install fails
Solution: Make sure Node.js is installed from nodejs.org

Problem: Port 3000 already in use
Solution: Run npx kill-port 3000 then npm start

Problem: Photos not showing
Solution: Make sure in public/photos/ folder, refresh page

Problem: Server won't start
Solution: Check terminal error, look for missing files

Problem: Admin panel loads but changes don't save
Solution: Check browser console (F12) for errors
