# 🎵 Background Music

Add your background music to this folder!

## How to Add Music

1. **Prepare your audio file**
   - Format: MP3, WAV, or OGG
   - Recommended: MP3 for best compatibility
   - Duration: Any length (usually 2-5 minutes for loop)

2. **Rename the file to: `background.mp3`**

3. **Place it in this folder** (public/music/)

4. **Restart the server** (if running) or refresh the page

## Music Sources

Find royalty-free music at:
- https://www.youtube.com/audio-library (Free, no account needed)
- https://www.bensound.com (Free with attribution)
- https://freepd.com (Free, public domain)
- https://www.incompetech.com (Royalty-free)

## File Size Tips

- Keep file size under 5MB for faster loading
- Use MP3 format for smaller file sizes
- Compress audio if needed (use Audacity or online tools)

## Music Controls

- Users can turn music on/off with the button on the page
- Music will loop continuously
- Click the button to control playback

Enjoy! 🎶
